The Second Attempt

This time, I actually had an USB.

So after mashing enter, booting from usb, scary terminal text, the Linux Mint logo appears.

So I quit the live boot and shrinked my Windows partition (cause i forgot) and had 130GB free space. The plan was to install Linux in the 130GB unallocated space.

Installing was an absolute pain, it really is. The freedom of many installation options can be confusing. You could install from the terminal, you could install from the software manager, you could install via apt from a .deb file, etc.

I was blown away. In Windows, background RAM usage is 4GB and i wasn't ran anything. Now? Running 15 tabs, a "lightweight" code editor (VS Code) and Play-in-Picture youtube.com for just a measly 5GB.

Was it worth it?

Yes.
